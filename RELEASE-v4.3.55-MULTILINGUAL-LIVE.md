# KoW Companion Multilingual v4.3.55 — LIVE Release Notes

## Production alignment
This Multilingual LIVE release is deliberately numbered **v4.3.55** to match the English LIVE v4.3.55 release.

The intermediate multilingual versions v4.3.56–v4.3.62 were TEST/QA builds used to validate and complete the translations. They are not separate production releases.

## Languages
- English
- French
- German
- Italian

French, German and Italian rendered/dynamic translation audits passed in the final QA build before promotion to LIVE.

## v4.3.55 functionality included
- Central Inventory shared throughout the app.
- Legendary Officer Badge Chest.
- Legendary Officer Badge Selection Chest.
- ORV and SRV Inventory.
- Universal Legendary, Epic and Elite Officer Badges.
- Elite, Epic and Legendary Star resources.
- XP Books.
- Individual Officer Badges for all supported Officers.
- Elite / Epic / Legendary badge filtering.
- Saved Officer progress and MAXED handling.
- Planner reads held individual Officer Badges and saved Officer progress.
- Original Legendary Officers do not use ORV.
- Seasonal Officers from S2 onward can use ORV/SRV where applicable.
- Selection Chest eligibility logic retained.
- Improved single-row navigation with horizontal scrolling on narrow displays.
- Inventory positioned prominently in navigation.
- Planner remains preview-only and does not consume Inventory.

## Multilingual QA
The multilingual TEST cycle added validation of rendered and dynamically generated strings in Planner, Help, Releases, Forecast, Database and other app sections.

The production build retains the validated translations but removes the TEST-only Translation Audit tooling.
